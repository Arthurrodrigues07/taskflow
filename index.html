Privacidade e armazenamento

O TaskFlow salva os dados localmente neste navegador. Não é necessário criar uma conta e nenhuma informação é enviada para um servidor pelo aplicativo. Limpar os dados do navegador pode apagar seus projetos e tarefas. Exporte backups regularmente.
