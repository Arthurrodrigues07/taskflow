
# TaskFlow

Gerenciador de projetos e tarefas desenvolvido com HTML, CSS e JavaScript puro.

O TaskFlow permite organizar múltiplos projetos, acompanhar o andamento das atividades e visualizar tarefas em um quadro Kanban ou em formato de lista.

## Demonstração

[Acessar TaskFlow](https://arthurrodrigues07.github.io/taskflow/)

## Funcionalidades

- Criação, edição e exclusão de projetos
- Gerenciamento de tarefas por projeto
- Quadro Kanban com movimentação de tarefas
- Visualização de tarefas em lista
- Dashboard com indicadores e progresso
- Prioridades, status e prazos
- Pesquisa, filtros e ordenação
- Salvamento automático com localStorage
- Exportação e importação de backup JSON
- Layout responsivo para computadores e celulares

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages

## Armazenamento

O TaskFlow utiliza localStorage para armazenar projetos e tarefas no próprio navegador, sem necessidade de cadastro ou banco de dados.

Os dados não são sincronizados entre dispositivos. É possível exportar um backup JSON e importá-lo posteriormente.

## Como executar

1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` no navegador.
3. Crie um projeto e comece a organizar suas tarefas.
